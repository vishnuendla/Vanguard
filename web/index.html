Reference

API reference

The dashboard is a client of the same authenticated JSON API. Use it for integrations, scripts, or evaluation.

Authentication

Bearer token

Every protected request needs a bearer token and an analyst identifier. The local demo uses local-demo-token.

Authorization: Bearer <token>
X-User-Id: <analyst-id>
Swagger UI ↗ OpenAPI JSON ↗

Base URL

Local

Run the API with uvicorn app.main:app --reload, then use:

http://127.0.0.1:8000

The demo token is disclosed only when the app is using the known local demo configuration.

Endpoints

Available routes

GET/api/healthPublic liveness check
GET/api/configDemo token hint; never returns a deployment token
GET/api/incidentsPrioritized queue; optional ?status=new
GET/api/incidents/{id}Incident with evidence and verification needs
PATCH/api/incidents/{id}/statusRecord a decision with a required rationale
GET/api/auditReview history; optional ?incident_id=...&limit=...
GET/api/vendorsMonitored vendor records

Example

Record a decision

curl -X PATCH http://127.0.0.1:8000/api/incidents/inc-northstar-logistics/status \
  -H "Authorization: Bearer $VANGUARD_TOKEN" \
  -H "X-User-Id: analyst-01" \
  -H "Content-Type: application/json" \
  -d '{"status":"relevant","rationale":"Two shipments need a recovery ETA."}'

Repeating the current status returns 409 so the audit log never records a no-op transition.
